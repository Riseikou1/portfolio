# Temuujin Gerelt-Och portfolio

Personal portfolio built with vinext. It presents selected AI projects, background, course certificates, and contact details.

## Local development

The development commands automatically use Node.js 22, including on machines where an older Node version is the default.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. To create a production build, run `npm run build`.

The source PDFs and images in `public/certificates/` are copies of certificates supplied for this portfolio. Contact details follow the Research GAP contact page.
